# Trening – siłownia

Aplikacja na telefon do treningu według planu „Etap II – Trening oporowy: maszyny” (2 dni).

## Jak zainstalować na Androidzie
1. Otwórz adres aplikacji w Chrome.
2. Menu ⋮ → **Dodaj do ekranu głównego** (lub **Zainstaluj aplikację**).
3. Od teraz uruchamiasz ją ikonką. Po pierwszym otwarciu działa też bez internetu.

## Ważne
- Historia treningów jest zapisana **tylko w telefonie**. Co jakiś czas użyj „Kopia zapasowa → Zapisz kopię”.
- Minutnik przerwy gra dźwięk i wibruje. Podczas treningu ekran nie gaśnie, żeby sygnał na pewno zadziałał. Nie wyciszaj multimediów w telefonie.

## Dla osoby, która zmienia aplikację
Po każdej zmianie plików podbij `VERSION` w `sw.js`, inaczej telefon pokaże starą wersję.
